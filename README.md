# LAST SAVE : 마지막 저장점

웹사이트에서 바로 플레이하는 스토리 픽셀 RPG. 프롤로그부터 4막, 엔딩 4종까지 처음부터 끝까지 플레이할 수 있다.

## 이야기 흐름

| 막 | 지역 | 메인 퀘스트 | 핵심 퍼즐 · 보스 |
| --- | --- | --- | --- |
| 프롤로그 | 빅윈의 작업실 | MQ00 테스트 플레이 | 시스템 에러 연출 |
| 1막 | 구름 위의 마을 | MQ01 흩어진 별지기 · MQ02 첫 번째 별 | 8명 합류, 시계탑 별 조각 |
| 2막 | 거울의 숲 | MQ03 비치지 않는 사람 | 도담히 기억 읽기 ×3 → 시로로 거울 각도 맞추기 |
| 2막 | 멈춰버린 놀이공원 | MQ04 개장 1분 전 | 톱니(돗챠)·제어반(뚜닝) → **멈춘 관람차** 보스 2페이즈 |
| 2막 | 잊힌 데이터 센터 | MQ05 정리 로그 | 논리 회로(뚜닝) → 서버실 봉인(빅윈) → **삭제 대기열** → 크론 로그 (중반 반전) |
| 3막 | 달빛 정원 | MQ06 한밤의 개화 | 빅윈 신뢰 선택지, 달 가리기(루뭉) → 달꽃 순서 개화(하밍) |
| 3막 | 사라진 기차역 | MQ07 마지막 역 | 측량(다래) → 선로 밀기(돗챠), 종착역 이름 선택 |
| 3막 | 사진 속 마을 | MQ08 없는 사진 | 측량(다래) → 옛 사진 겹치기(으네), 첫 사진 주인공 선택 |
| 4막 | 그림자의 도시 | MQ09 포인트 | **크론 추격** (꽃등으로 시야 끊기), 포인트 정체·빅윈 고백, 포인트 반환/보류 선택 |
| 4막 | 마지막 저장소 | MQ10 마지막 저장점 | **크론 최종 이벤트** (기억마다 만든 사람 고르기) → 최종 선택 |
| 시크릿 | 휴지통 섬 | — | 트루 엔딩 + 버그 노트 27개 |

- 막 안에서는 지역 순서를 자유롭게 고른다. 하늘 정류장에서 이동 (처음 가는 곳 2시간, 가 본 곳 1시간)
- 엔딩: **초기화**(시간 0 또는 "저장하지 않는다"), **노멀**(세계 기억 8), **트루**(+핵심 기억 9 + 저장 열쇠 + "새 기억을 만든다"), **시크릿**(트루 + 버그 노트 27)
- 보스는 HP 전투 없이 안정도 게이지 퍼즐. 실패하면 1시간이 흐르고 다시 도전
- 서브 퀘스트 18개 (SQ01~SQ18), 개인 에피소드 9개 (담당 지역 별 + 유대 3에서 열림, 2시간)
- 유대 0~5: 퍼즐·서브 퀘스트·휴식 대화(12종)·선택지로 오른다. 유대 5면 최종장에 추가 대사
- 수집: 세계 기억 8, 핵심 기억 9, 버그 노트 27 (일부는 다래 측량으로만 보임), 앨범 사진 36 (으네로 촬영)
- 상점 (빵집 할머니 · 정원사 라일 · 그림자 상인): 별사탕(빅윈 권한 충전), 따뜻한 차(휴식 4시간), 구름솜(발판 2배), 액세서리 3종
- 오류 진행도: 별을 못 켠 지역은 검은 픽셀이 번져 있고, 남은 시간이 24시간 아래면 더 심해진다

## 계정 · 저장 (Supabase)

- 게임을 시작하려면 로그인해야 한다. 회원가입은 아이디·비밀번호만 (이메일 인증 없음), 가입하면 바로 로그인된다.
- 포인트(★)에서 저장하면 계정에 저장되고, 다른 기기에서 같은 아이디로 로그인해도 이어할 수 있다. 서버에 닿지 않을 때만 이 기기에 사본을 둔다.
- Supabase 프로젝트 `last-save` (서울 리전). 테이블 `ls_players` · `ls_sessions` · `ls_saves`는 직접 읽을 수 없고 `ls_signup` `ls_login` `ls_me` `ls_save` `ls_load` `ls_clear` `ls_logout` 함수로만 접근한다. 비밀번호는 bcrypt로 해시, 로그인 토큰은 해시로 저장(60일).
- 스키마: `supabase/migrations/`, 접속 주소·공개 키: `packages/game/src/config.ts`

## 9명의 능력

| 캐릭터 | 능력 (Q / B) | 하는 일 |
| --- | --- | --- |
| 루뭉 | 구름 걸음 | 빈 하늘에 발판, 달 가리기 |
| 도담히 | 기억 읽기 | 잔향(✦)이 남은 물건의 과거 장면 재생 |
| 돗챠 | 돌진 | 바위 부수기, 블록 밀기, 레이스 가속 |
| 뚜닝 | 해석 | 단말기·제어반·회로 퍼즐 |
| 빅윈 | 설계자 권한 | 잠긴 상자·봉인 해제 (충전 횟수 제한, 기억을 되찾을수록 늘어남) |
| 하밍 | 개화 | 덩굴, 달꽃, 꽃등·꽃 간판 |
| 다래 | 측량 | 지도 오버레이 + 숨은 오브젝트·노트 드러내기 |
| 으네 | 기록 | 촬영 지점에서 앨범 사진, 옛 사진 겹치기 |
| 시로 | 밤눈 · 고양이 길 | 어두운 지역을 밝게, 좁은 창살 통과, 검은 고양이가 보임 |

## 조작

| 동작 | PC | 모바일 |
| --- | --- | --- |
| 이동 | WASD (방향키도 가능), Shift 달리기 | 왼쪽 조이스틱 (끝까지 밀면 달리기) |
| 대화 · 결정 | Space / E / Enter | A |
| 능력 | Q | B |

| 퀘스트 · 가방 · 지도 | J · I · M | ≡ 메뉴 안에서 |
| 메뉴 | Esc | ≡ |
| 설정 | — | ⚙ 설정: 버튼 크기·투명도·진동·버튼 숨기기·전체화면 |
| 전체화면 | F 또는 오른쪽 아래 버튼 | ⚙ 설정 안에서 |

## 실행

```bash
cd packages/game
npm install
npm run dev            # 개발 서버
npm run build          # dist/ 정적 빌드 (Cloudflare Pages에 그대로 올리면 됨)
npm run build:single   # dist-single/index.html 한 파일 빌드
```

## 어디를 고치면 되나

| 고칠 것 | 파일 |
| --- | --- |
| 대사 · 선택지 | `src/story/main.ink`(프롤로그·1막), `act2.ink`, `act3.ink`, `act4.ink`(엔딩 포함), `episodes.ink`(개인 에피소드·휴식) |
| 지역 퀘스트 · 오브젝트 · 퍼즐 정답 | `src/world/content.ts` |
| 퍼즐 미니게임 화면 | `src/scenes/PuzzleScene.ts` (순서 · 다이얼 · 타이밍 · 컨베이어 · 수호) |
| 퀘스트 창 문구 · 아이템 이름 | `src/data/quests.ts` |
| 캐릭터 이름 · 색 · 능력 이름 | `src/data/characters.ts` |
| NPC 이름 · 그림 | `src/world/maps.ts`(이름·대사), `src/assets/npc/<id>.png`(필드 그림), `<id>_por_smile/surprise/sad.png`(표정) |
| 맵 충돌 · 위치 | `tools/maps/config.py` → `python3 tools/maps/build.py` → `python3 tools/maps/collision.py` (사물·길 구분: `collision_fix.py`에 맵별로 막을 칸 `block` · 열 칸 `open` 사각형, 타일 좌표) → `python3 tools/maps/occlusion.py` (가로등·거울 같은 소품 뒤로 캐릭터가 가려지는 조각) → `python3 tools/maps/check.py` (도달성) |
| 막힌 길 검사 | 빌드 후 `dist`를 8766 포트로 띄우고 `python3 tools/test/walk_all.py cloud,mirror,...` (모든 오브젝트·NPC까지 실제로 걸어 봄) |
| 키 배치 | `src/systems/InputManager.ts` |
| 저장 구조 | `src/systems/SaveManager.ts` (IndexedDB, 내보내기/가져오기 함수 포함) |

대사 줄 형식은 `화자ID: 대사`. 화자ID는 `me`(선택한 주인공), `sys`, `narr`, `point`, 캐릭터 id, NPC id(`spirit`, `cron` 등). 줄 끝 태그: `#glitch` 화면 깨짐, `#tower_light` 별 켜짐, `#quest` 퀘스트 알림, `#save` 저장, `#e_smile` `#e_surprise` `#e_sad` 표정.

## 사이트에 붙이기

`src/main.ts`의 `startGame(gameEl, touchEl)`을 Next.js 페이지의 클라이언트 컴포넌트에서 호출하면 된다. 게임 영역 div와 모바일 버튼 div 두 개만 넘기면 됨.

## 사이트 (packages/site)

Next.js 정적 사이트: 타이틀 화면 랜딩, 세이브 슬롯(캐릭터 소개), 세이브리아(막·지역), 조작, `/play/`(게임), `/wiki/`(공략 위키 — 내용은 `lib/wiki.ts`, 게임 퍼즐 정답을 바꾸면 여기도 같이 고치기).

```bash
cd packages/game && npm install && npm run build   # 게임 먼저
cd ../site && npm install && npm run build         # out/ 폴더가 완성된 사이트
```

Cloudflare Workers(Git 연결): 빌드 명령 `cd packages/game && npm ci && npm run build && cd ../site && npm ci && npm run build`, 배포 명령 `npx wrangler deploy` (설정은 루트 `wrangler.jsonc`, 정적 파일 폴더 `packages/site/out`).
