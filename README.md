# LAST SAVE : 마지막 저장점 — 1막 (P2)

웹사이트에서 바로 플레이하는 스토리 픽셀 RPG. 프롤로그와 1막 「구름 위의 마을」까지 플레이 가능.

## 들어간 것

- 타이틀 → 캐릭터 선택(9명) → 프롤로그(시스템 에러 연출) → 구름 위의 마을
- 흩어진 8명 찾기 + 합류 대사, 합류하면 뒤에서 따라옴
- 캐릭터 교체 (숫자키 1~9, Tab, 모바일 교체 버튼)
- 능력 2종: 루뭉 구름 걸음(빈 하늘에 발판), 돗챠 돌진(금 간 바위 파괴). 나머지는 안내 문구
- 포인트(★)와 대화 → IndexedDB 저장, 타이틀에서 이어하기
- 버그 노트 3개 수집, 하밍 합류 시 화단 개화(선택지 반영)
- 8명 모두 모으면 시계탑 소멸 + 크론 첫 등장
- MQ02 첫 번째 별: 시계탑 별 조각 3개(구름 걸음·돌진 필요) → 시계탑 복구, 세계 기억 1, 하늘 정류장 개방 → 1막 완료
- 서브 퀘스트: 바람개비 우체부(편지 5통), 이름 없는 이웃(주민 3명)
- 72시간 타이머 실제 소모 (지역 이동 2, 메인 이벤트 2, 서브 1, 휴식 6), 0이 되면 초기화 엔딩
- 포인트에서 휴식 → 두 캐릭터 밤 대화 (유대 +1)
- 퀘스트 창(J), 가방(I), 일시정지 메뉴(Esc)
- BGM(타이틀·마을 왈츠)과 효과음 — WebAudio 합성, 음소거 지원

## 조작

| 동작 | PC | 모바일 |
| --- | --- | --- |
| 이동 | WASD (방향키도 가능), Shift 달리기 | 왼쪽 조이스틱 (끝까지 밀면 달리기) |
| 대화 · 결정 | Space / E / Enter | A |
| 능력 | Q | B |
| 교체 | 1~9, Tab | 아래쪽 캐릭터 얼굴 버튼 (번호 = PC 숫자키) |
| 메뉴 | Esc | ≡ |
| 설정 | — | ⚙ 설정: 버튼 크기·투명도·진동·버튼 숨기기·전체화면 |
| 전체화면 | F 또는 오른쪽 아래 버튼 | ⚙ 설정 안에서 |

모바일 버튼은 터치 기기에서만 나타나고, 세로 화면이면 게임 아래 영역으로 내려간다.

## 실행

```bash
cd packages/game
npm install
npm run dev            # 개발 서버
npm run build          # dist/ 정적 빌드 (Cloudflare Pages에 그대로 올리면 됨)
npm run build:single   # dist-single/index.html 한 파일 빌드
```

## 어디를 고치면 되나

| 고칠 것 | 파일 |
| --- | --- |
| 대사 · 선택지 · 스토리 | `src/story/main.ink` (Ink 문법, 빌드할 때 자동 컴파일 · 문법 오류는 빌드 실패로 표시) |
| 캐릭터 이름 · 색 · 능력 이름 | `src/data/characters.ts` (이름 표기 확정되면 여기만 수정) |
| 마을 지형 · 캐릭터 위치 · 버그 노트 | `src/world/cloudVillage.ts` |
| 키 배치 | `src/systems/InputManager.ts` |
| 모바일 버튼 모양 · 위치 | `src/ui/TouchPad.ts`, `src/style.css` |
| 걷기 시트 (4방향 × 4프레임) | `src/assets/walk/<id>.png`, 칸 크기는 `src/data/characters.ts`의 `WALK` |
| 저장 구조 | `src/systems/SaveManager.ts` (IndexedDB, 내보내기/가져오기 함수 포함) |

대사 줄 형식은 `화자ID: 대사`. 화자ID는 `me`(선택한 주인공), `sys`, `narr`, `point`, 캐릭터 id. 태그 `#glitch` `#save` `#chapter_end`가 연출을 부른다.

## 사이트에 붙이기

`src/main.ts`의 `startGame(gameEl, touchEl)`을 Next.js 페이지의 클라이언트 컴포넌트에서 호출하면 된다. 게임 영역 div와 모바일 버튼 div 두 개만 넘기면 됨.
